Realtek R8152 USB Ethernet Driver
==================================

This directory is for Realtek R8152/R8153/R8156 USB Ethernet adapter drivers.

Expected contents:
- DKMS source packages
- Firmware files
- Installation scripts

Supported devices:
- RTL8152 (USB 2.0 Fast Ethernet)
- RTL8153 (USB 3.0 Gigabit Ethernet)
- RTL8156 (USB 3.0 2.5G Ethernet)

Note: Many modern kernels include built-in support for these devices.
This driver vault is for cases where newer driver versions are needed
or the built-in drivers are not functioning correctly.
