Realtek R8821CU USB WiFi Driver
================================

This directory is for Realtek RTL8821CU USB WiFi adapter drivers.

Expected contents:
- DKMS source packages
- Firmware files
- Installation scripts

Supported devices:
- RTL8821CU (USB 2.0 WiFi AC)
- RTL8811CU (USB 2.0 WiFi AC)

Note: These drivers often require out-of-tree DKMS modules as
mainline kernel support may be incomplete or missing.

Common chipset IDs:
- 0bda:c811
- 0bda:c820
- 0bda:c821
